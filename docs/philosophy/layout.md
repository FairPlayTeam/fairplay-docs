# Layout

Why does FairPlay's interface look like YouTube's?

This is a question we get asked a lot.

Yes, FairPlay's interface is heavily inspired by YouTube's.

As explained on the previous pages, FairPlay is primarily aimed at people who already use traditional video platforms and are looking for a more open and transparent alternative.

And these users are already very familiar with YouTube's interface.

They already know where the buttons are, where to search for a video, how to access comments, and where to find information about a video.

We prefer to focus our energy on improving the experience rather than reinventing a UX that already work.

This doesn't mean we're simply replicating YouTube.

When we think an interface can be improved, simplified, or made more consistent with the project's values, we don't hesitate to deviate from it (e.g., star ratings).

If you quickly find what you're looking for and use FairPlay naturally from the very first minutes, then we consider this design choice to have fulfilled its purpose.
